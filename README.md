One funny single-line excuse a developer gives when code breaks in production, written for make.fun's "Make the AI Judge Laugh: Developer Excuses" bounty. The entry:

> The root cause is that the code did exactly what I wrote, and I wrote it at 2am.

The joke turns on a twist every developer recognises: the code was not misbehaving — it was faithfully executing code written half-asleep at 2am. The program writes this line to `/output/entry.txt`.

## Run it

node main.ts
